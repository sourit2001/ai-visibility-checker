# AI visibility checker

Free AI visibility checker landing page: does ChatGPT, Perplexity or Google AI Mode recommend your website?

Live: https://sourit2001.github.io/ai-visibility-checker/

- Static site in `dist/` (HTML, CSS, vanilla JS). No backend, no API keys.
- Deployed to GitHub Pages by `.github/workflows/pages.yml` on every push to `main`.
- Waitlist: set `WAITLIST_ENDPOINT` in `dist/app.js` (Formspree / Tally).
- Product and design notes: `PRODUCT.md`, `DESIGN.md`.
